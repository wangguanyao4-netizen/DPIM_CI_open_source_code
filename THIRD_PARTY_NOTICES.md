# Third-party dependencies

The root MIT license covers the project source released by Guanyao Wang,
including the author-approved supplied FE/KL source and its Python port.
It does not replace the licenses of external software.

- MATLAB and Statistics and Machine Learning Toolbox are proprietary MathWorks
  products installed by the user. No toolbox source or installation is bundled.
- NumPy, SciPy, SymPy, pandas, threadpoolctl, pypdf, and ReportLab retain their
  respective BSD-style licenses and component notices.
- Matplotlib retains its PSF-based license and bundled asset notices. Pillow
  retains its HPND and component notices.
- LaTeX, PGF/TikZ, and fonts used by original diagrams are separate installations.
  No Windows font files are distributed in this repository.

Some archived production scripts used PyMuPDF for local PDF checking. PyMuPDF
is available under AGPL or a commercial license; it is not bundled, and the
project's MIT grant does not cover that dependency. The publicly executable
plotting collection avoids requiring that local checking tool where practical.
The archive records original source behavior without claiming all dependencies
have MIT licenses.

The source provenance files identify the numerical and plotting code used in
this paper. No third-party journal article or commercial solver binary is
redistributed here.
