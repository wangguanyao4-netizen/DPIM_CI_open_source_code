# MATLAB Code Archive

This release preserves computation code already used for the manuscript. It
does not introduce a new campaign, a new random-stream protocol, or a promise
of from-scratch reproduction. No MATLAB, numerical experiment, coefficient
integration, or MATLAB test was run while preparing these files. Preparation
checks were limited to source inspection and SHA-256 comparison of code.
This is a code-only release: no coefficient CSV, other CSV data, MAT archives,
raw pools, fixtures, or PDF artifacts are distributed.

## Included Core

- `matlab/+dpim/tc_intervals_from_original.m` is a byte-for-byte copy of the
  existing authoritative interval function, including its original name.
- `config/matlab_source_manifest.json` records package-relative archive
  locations and original/published code hashes, and identifies external data
  dependencies that are not included.
- `matlab/setup_dpim.m` only adds the package's MATLAB directory to the path.
  It does not import Python, change random streams, start tests, or launch an
  experiment. Historical campaigns are not added to the path automatically.

From the release root, the path-only setup is:

```matlab
addpath('matlab');
setup_dpim;
```

For an existing numeric matrix `x`, the preserved function has the signature
`dpim.tc_intervals_from_original(x, B, alpha, substream, streamSeed)`. Rows of
`x` are complete outer curves and columns are response locations. The caller
must establish whether those curves are fresh or sampled from a fixed pool.
The function does not manufacture curves or choose a target/reference density.

The three output rows are Student t, raw percentile bootstrap, and bootstrap t.
The original finite-B floor/ceil endpoint ranks, Threefry bootstrap indices,
stable-variance fallback, ties, zero-variance, and infinite-pivot rules are
unchanged. The fifth argument defaults to 20260922 in the original function;
historical callers sometimes supplied a different seed. A matching substream
alone is therefore insufficient to reproduce a trial.

MATLAB and Statistics and Machine Learning Toolbox are external requirements.
The original interval function uses `RandStream('Threefry',...)` and `tinv`.
Historical design/response programs additionally use `sobolset`, `scramble`,
`net`, `norminv`, and Python NumPy/SciPy FE/KL components. This archive does not
claim Octave support or cross-version, cross-language bitwise equivalence.

The historical finite-B simulation table was generated by the local
`localRunFiniteB` and `localSimulateFiniteBOrderStatisticCoverage` functions
in `run_weighted_paper_evidence_suite.m`, not by a theoretical-rank-only
baseline script. This does not make the full evidence suite a release entry
point or authorize treating unrelated experiments as part of this paper.

The coefficient CSV is a separate, external dependency of historical formula
and recommended-R calculations. It is not included in this release and no CSV
contents are certified by this preparation. Users must supply their own
coefficient CSV or generate it using the preserved coefficient-calculation
module, `python/dpim_paper/coverage_coefficients.py`, through its
`direct_coefficients(alpha, B)` function, for alpha 0.05 and B 399/999.
That function returns coefficient records and diagnostic metadata; those
records must be exported to the CSV format and location expected by the
historical caller. Generation and export are not performed automatically by
the MATLAB setup. The standalone interval function does not read a coefficient
CSV. The finite-B simulation table described above is not a substitute for
these coefficient records.

## Parameter And Replay Boundaries

| Experiment | Existing manuscript parameters and interpretation |
| --- | --- |
| Initial design | A fixed scrambled Sobol or fixed MC base; periodic Voronoi assignment with 50000 auxiliary uniform points; probabilities remain fixed across common modulo-one shifts |
| Euler primary coverage | n 768, R 32/128, B 399, M 30000; independent shifts and analytic Gaussian-smoothed reference, h 0.08 |
| Plate primary coverage | n 200, R 16/128, B 999, P/M 30000; coverage conditional on the stored pool; h 1.10742439018982e-6 |
| Plate reference | 16 independent scrambled Sobol groups of 131072 points, total 2097152; standard error across group means |
| Nonlinear primary coverage | n 768, R 16/128, B 399, P/M 50000; coverage conditional on the stored pool; h 0.08; final reference uses 500000000 independent MC responses |
| Internal n comparison | n 192/384/768, R 128, B 399, P/M 30000; separate from nonlinear primary M 50000 |
| Recommended R | Uses stored pilot moments and finite-B coefficients; concrete intervals use fresh shifts. Final nonlinear reference replacement did not regenerate the archived endpoints |

The original coefficient calculation includes the percentile
distribution-free `A0/R` term; an externally supplied or regenerated CSV must
preserve that convention.
Coefficient formulas and pilot-based R calculations are not finite-sample
coverage guarantees. Pool-conditional coverage is not independent population
coverage. Small historical diagnostics are not formal manuscript evidence.

Historical production used multiple expansions and reused existing MAT
prefixes, fixed designs, grids, KL modes, references, and endpoint batches.
Several historical entry points immediately load those archives; others can
start substantial work when called. They are source records, not safe default
launchers. Neither this directory nor the code-only source archive supplies
the raw pools, coefficient CSVs, complete MAT histories, or a first-trial
fixture. References to stored inputs describe historical external
dependencies, not files shipped in this release. Without those inputs the
historical campaigns are not an out-of-the-box, from-zero reproduction route.

For exact archived replay, the original design, input arrays, all stream
seeds/substreams and boundary rules, grids, B/R, and numerical environment
must be available. Recomputing paper-sized parameters from a new stream is
not the same claim. This preparation neither executed nor verified either
route and did not create a replacement random-stream implementation.

Private interpreter paths in archived drivers must be supplied by a user's
environment or explicit parameters, not copied from a workstation. Do not
assume that a renamed/refactored Python bridge is automatically compatible
with an unchanged historical MATLAB caller. The production-source archive
and its original bridge interface remain the reference for that dependency.
