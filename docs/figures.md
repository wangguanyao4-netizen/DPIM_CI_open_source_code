# Publication Figures and Historical Production

## Scope and Status

This is a **code-only release**. Numerical data and figure assets are not
distributed: no CSV results, reference densities, interval endpoints, curve
slices, raw pools, MAT/NPZ archives, PDF figures, or manuscript are supplied.
**All numerical plotting and table inputs must be provided by the user.**
The 17 figure filenames identify historical outputs, not files included in the
repository. Expected comparison PDFs are optional external references.
No plotting, MATLAB, numerical experiments, or tests were run for this
documentation-only change; no fresh reproduction is claimed.

`provenance/figure_table_registry.json` maps each figure/table to public source
files, required external input filenames, dependencies, commands and unresolved
points. Its `inputs` paths are relative to the user-selected data directory;
its `expected` paths describe optional user-supplied comparison PDFs, not
distributed assets. PDF/data hashes are not part of this code-only inventory.
`provenance/plot_sources.json` lists public source-code and TeX files only,
with retained source hashes and upstream source provenance. It does not list
data or PDF files as release contents. Upstream identifiers are relative source
provenance, not a requirement for a private absolute path.

The copied numerical plotting routines retain the production algorithms,
geometry, font sizes, colours, reference-data interfaces, interval viewports and local
circular enlargements. Changes are limited to input/output adapters, removing
private paths, removing manuscript/preview side effects, and carrying the
approved `pdf` labels and full mechanism legend names. This is not a new
Python implementation of the numerical experiments. Adapted code is unexecuted.

## External Input Requirements

No `data/publication/` directory is distributed. Provide a local directory
containing the files required by the chosen plotter and pass it explicitly
using `--data-dir` or the MATLAB `dataDir` argument. The historical default path
in some source files does not imply that data is included. The following are
input contracts and production parameters, not released numerical results.

| User-supplied filename | Required selection and interpretation |
| --- | --- |
| `coverage.csv` | 150 Euler and 150 plate rows at M=30000 from the current M30000 CSV; all old nonlinear rows excluded; 150 nonlinear P=50000, M=50000 rows appended from final 500M-reference recount |
| `euler_pool_control.csv` | 150 M30000 control rows, if needed, kept separately with `dataset` and `experiment_type`; not independent primary evidence |
| `coverage_summary.csv` | Current linear/plate M30000 summaries including labelled control, plus nonlinear 500M-reference summaries only |
| `reference_linear.csv`, `reference_plate.csv` | User-supplied production reference density ordinates; not generated by the plotters |
| `reference_nonlinear_density.csv`, `reference_nonlinear_coverage.csv`, `reference_nonlinear_n_density.csv` | Final nonlinear reference grids; 500M reference does not mean 500M coverage trials |
| `internal_n.csv` | n=192/384/768, P=M=30000, R=128, B=399; nonlinear M50000 is not used for this comparison |
| `intervals_linear_nonlinear.csv` | Euler rows from the original full-precision refresh CSV; nonlinear rows from the selected final500M CSV; existing independently generated interval endpoints are retained |
| `intervals_plate.csv` | Production plate MC/RQMC recommended-R intervals |
| `recommended_R.csv` | Supply nonlinear RQMC recommendations from P50000 and MC recommendations from P30000. Do not imply that the earlier independent endpoints were regenerated |
| `saved_trial_intervals.csv`, `table_interval_values.csv` | Historical first-trial schema: 450 full-grid rows and 126 selected endpoint rows. The table adapter needs the externally supplied 126-row CSV; neither file is distributed |
| `finite_B_summary*.csv` | User-supplied archived finite-B table evidence; no simulated values are distributed |
| `outer_workflow_curves.csv` | A headerless 256-by-201 array of real Euler pilot ordinates, supplied externally, with columns matching `reference_linear.csv`. Do not substitute a newly simulated illustration and call it historical reproduction |

Core CSV fields used by the plotting/table sources are:

- Coverage: `model,method,R,B,M,y,coverage,cp95_lower,cp95_upper,formula_prediction`,
  with `P,reference_N` for the nonlinear provenance checks and the original
  `scheme,n,dataset,experiment_type` fields where applicable.
- Reference density: `y,reference_density`.
- Internal-n: `model,method,n,R,B,M,y,coverage`; retain the original protocol fields.
- Recommended-R interval curves: `scheme,model,method,n,R,B,y,reference_density,sample_mean,sample_sd,ci_lower,ci_upper`.
- First-trial endpoints: `model,trial,location_index,y,reference_density,n,pool_size,M,B,R,method,lower,upper,sample_mean`.

Use the method strings expected by the historical source, including
`Student t`, `percentile bootstrap`, and `bootstrap-t` for numerical figure CSVs;
the first-trial table CSV uses `bootstrap t`. Preserve precision and the original
reference/endpoints pairing. Original plotters may interpolate for display or
omit extreme bootstrap-t intervals from the viewport; neither operation makes
the inputs available or recalculates coverage. Pointwise intervals are not
simultaneous bands. Exact original ordinates are necessary for exact historical
numerical figures, not just schema-compatible replacements.

## Historicalproduction Commands

Commands below are documentation for a user who elects to render later.
**They were not executed for this release.** Run them from the release root only
after obtaining the required inputs independently. Replace `<user-data-dir>`
with that external directory; it is not a directory shipped by this repository.
Outputs default to a new timestamped `outputs/` directory, or use an explicit
new output directory. Existing output directories are refused. Importing the
adapters does not start plotting. There is no default formal/full experiment.

### Five Python Numerical Figures

```powershell
python plotting/historicalproduction.py --kind python --data-dir "<user-data-dir>" --output-dir outputs/python_figures
```

This feeds the archived `plot_linear_plate_real_data_mechanisms.py`,
`plot_nonlinear_real_data_mechanism.py` and extracted `internal_n.py` functions.
The historical terminology, separator-spacing, full-name legend and `pdf`
adapters are in `labels.py`, `spacing.py` and `current_labels.py`. The inputs are
user-provided current merged coverage, three reference densities and internal-n CSV.
No experiment, coverage estimation or MATLAB is invoked by this command.

Dependencies: Python 3.10+, NumPy, pandas, Matplotlib; original numerical figure
text uses Times New Roman with STIX math. Provide the original font locally to
retain production typography. Fonts are not distributed. No PyMuPDF dependency.

### Six MATLAB Numerical Figures

```matlab
addpath('plotting/matlab');
replay_matlab('<user-data-dir>', 'outputs/matlab_figures');
```

`plot_nested_M_paper_style.m` draws the three coverage PDFs.
`plot_intervals_pdf_label_only.m` draws the three recommended-R PDFs, preserving
the original circular windows, viewport masks and font settings. Both use
externally supplied saved CSVs only. MATLAB `-batch` may be used explicitly; the Python adapter
does not launch MATLAB. Production used MATLAB R2026a; this copied plot-only
subset and other MATLAB versions have not been tested here. No Octave claim.

### First-Trial Endpoint Tables

```powershell
python plotting/historicalproduction.py --kind tables --data-dir "<user-data-dir>" --output-dir outputs/tables
```

`tables.py` is the archived table formatter with I/O redirected away from the
paper. It reads the user's 126 selected rows and writes three TeX fragments and an
output copy of the selected CSV. Plate display units and five-decimal printing
are unchanged; source CSV values are not rounded. The fragments require the
host TeX document's `booktabs` and `caption` support. Recommendation and finite-B
table values are not supplied either; the registry describes their external
input requirements and historical preparation source.

### Six Static Figures

```powershell
python plotting/historicalproduction.py --kind transport --output-dir outputs/transport
python plotting/historicalproduction.py --kind plate --output-dir outputs/plate_model
python plotting/historicalproduction.py --kind euler --output-dir outputs/euler_model
python plotting/historicalproduction.py --kind shift --output-dir outputs/random_shift
python plotting/historicalproduction.py --kind framework --output-dir outputs/framework
python plotting/historicalproduction.py --kind outer --data-dir "<user-data-dir>" --output-dir outputs/outer --font-roman <local-times-roman.ttf> --font-italic <local-times-italic.ttf>
```

| Figure | Source and remaining boundary |
| --- | --- |
| Probability transport | `static/draw_transport.py`; original illustrative construction, `pdf` label. No experiment data needed |
| Euler model | `static/euler_model.tex`; original standalone TikZ. Needs `pdflatex`, `standalone`, `amsmath`, TikZ |
| Plate model | `static/draw_plate.py`; original ReportLab vector drawing. The separate raster preview and font-path assumptions were removed |
| Random shift | `static/shift_layout.py` contains the final historical 10-pt arrow-tip correction, calling `shift_geometry.py` and `method_geometry.py`; not merely the earlier v6 export. Needs Matplotlib/NumPy and external TeX/PGF, `lmodern`, `amsmath`, `amssymb`, `bm` |
| Unified framework | `static/framework_layout.py` calls `framework_geometry.py` and `method_geometry.py`; original spacing/formula fixes preserved. Same TeX/PGF dependencies; current approved PDF equivalence remains unverified |
| Outer workflow | Only `static/outer_workflow.py` and the later `static/outer_overlay.tex` are included; the real ordinate slice and density grid must be supplied externally. The automatic historical overlay is earlier than the approved overlay. The generated background plus the later overlay must be reconciled before claiming an exact current-version rebuild. Needs ReportLab, NumPy, external XeLaTeX/TikZ/fontspec and user-installed fonts; optional `dvisvgm` |

For the outer-workflow candidate, after the background exists the later overlay
can be compiled from its output directory using `xelatex -no-shell-escape
-interaction=nonstopmode -halt-on-error outer_overlay.tex`. Its optional external
comparison reference is `Fig01b_outer_sample_workflow.pdf`, which is not
distributed. Neither background equivalence nor this
two-step production chain was validated in this release. Do not promote it to
`codecomplete` without that check. The static constructions are illustrations,
not new numerical evidence. No current static figure is marked freshly tested.

TeX is an external, locally installed tool. Ensure all packages are installed
before rendering and disable automatic package installation for offline use.
The scripts do not download dependencies. PyMuPDF/AGPL-based preview and QA code
was not copied into the runtime; independent future PDF QA may use pypdf or
an external renderer.

## Maintainer Notes

`prepare_publication.py` is retained as historical preparation source, not as
a code-only publication step. If explicitly run against a user-owned archive,
it can recreate local data/PDF copies. Such outputs must remain private and
must not be added to this code-only release. It is not a source of downloadable
data and must not be pointed at the public repository as its archive. Nothing
in this revision invokes it or recreates removed assets.

Data-dependent publication tests are not distributed. The code-only release
uses `scripts/check_release.py` for standard-library static scanning in CI;
it is not numerical validation or a figure-reproduction test. No checks were
run for this cleanup. All plotting source and TeX remain unchanged.
Retained source hashes are provenance, not a new execution receipt. There is
no fresh scientific verification, source-rights audit, or cross-machine
execution claim. No commit or push was performed here.
